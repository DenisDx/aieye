# AI eye

Легкая прошика, позволяющая делать снимки с камеры через HTTP

## Компоненты:

### Конфигурация
Храним конфигурацию устройства в NVS. Лучше сделать объект вроде Config или Settings

### WEB gui
Предназначен для изначальной настройки на вайфай и изменение параметров. 
Отправляет HTML файл (надо создать его в каталоге) с нужными стилями и скриптами для удобной настройки
Показывает (с обновлением через web socket или как-то еще) статус устройства, позволяет редактировать настройки (файфай, качество снимка, безопасность... TBD)
предварительный список настроек
- WiFi: сеть и пароль
- Качество JPEG по умолчанию (по умолчанию 0.9)
- Разрешение JPEG по умолчанию (максимальное по умолчанию)
- TODO: Настройки прав и безопасности (пока делаем без этого)
- TODO: настройки SSL???? (пока делаем без этого)

Все поля должны быть на английском языке! Предусмотреть подсказки.

Добавить показ того, что видит камера (делать снимки раз в секунду, например) - прям через /photo endpoint


### captive portal over web server
показывает WEB gui через собственную точку доступа если вайфай не настроен или не может подключиться в течении некоторого времени (во втором случае нужно периодически делать попытки подключения)

### `/photo`  backend
Позволяет сделать фотографию с камеры и получить ее в JPEG
должен поддерживать post и get , но в начале делаем просто get
без параметров - делает фото и возвращает

### `/reboot`  backend
перезагружает прошивку

### `/settings`  backend
возвращает настройки в виде json; 
на входе 
POST: получает новые настройки в виде json (может быть частично)
GET: получает значения для изменения в строке запроса, например .../settings?reboot_every_s=80000

### `/status` backend
возвращает статус (json)

### `/` backend
возвращает HTML страницу с настройками, возможностью просмотра и т.п.

## Дополнительные требования
### переодическая перезагрузка
в настройках должен быть параметр reboot_every_s
перезагружать каждые это количество секунд.
Если идет активный процесс - перезагрузка должна быть отложена до его завершения

### Разносить разные функции по модулям. 
Отдельно- вебсерверная часть (объект внутри)
Отдельно объект, отвечающий за конфигурацию
Отдельно все, что связано с камерой 
и т.п.

### Документация
Всё на английском языке!
Каждая фунция должна иметь описание - что делает, и описание каждого параметра (и возврата)
